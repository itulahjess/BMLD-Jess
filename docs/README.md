## App-Beschrieb
Kaitas wurde entwickelt, um eine übersichtliche Verwaltung aller Abonnemente zu ermöglichen und das Geldmanagement zu unterstützen. Durch die Aboverwaltung wird ein ein klarer Überblick über Abonnements, Budgets, Ausgaben und Sparzielen erschafft.
